# Правило portable-сборки

- Не пересобирать EXE без прямой команды пользователя. Запрет включает `npm run pack`, `npm run release:build`, прямой запуск `electron-builder` и другие команды, создающие новый EXE. Проверки исходников, тесты и краткий запуск приложения из исходников разрешены.
- После каждой прямо разрешённой пересборки EXE выполнить `npm run verify`, затем создать Git-коммит и отправить его через `git push`. Не объявлять пересборку завершённой, если проверка, коммит или push не прошли; сообщить пользователю точную причину.
