# Офлайн-показ с флешки

Скопируйте `dist/Chuba-Sprite-Lab-portable.exe` на флешку. Для показа не требуется
установка Node.js, Python или отдельная загрузка моделей. Windows x64 распаковывает
portable-приложение во временную папку; на диске компьютера должно быть достаточно
места для приложения, моделей и рабочих кадров.

В комплекте:

| Модель | Инструмент |
| --- | --- |
| U²-Net small | Удаление фона |
| LaMa | Заполнение области по нарисованной маске |
| RIFE | Промежуточные кадры |
| Real-ESRGAN anime 6B | Увеличение рисованного кадра в 4 раза |
| Depth Anything V2 Small | Относительная карта глубины |

Дополнительные модели сегментации из каталога требуют отдельной загрузки. Эти пять
моделей встроены; сеть нужна только для обновлений и необязательных моделей.
Помощник выбирает сценарии локальными правилами: языковая модель в комплект не входит.
Ограничения размеров и качества каждого этапа сохраняются; увеличение не гарантирует
восстановление точного исходного пиксельного рисунка.

## Проверка EXE с чистым профилем

```powershell
& .\Chuba-Sprite-Lab-portable.exe --self-test --self-test-all-models --self-test-user-data C:\Temp\chuba-clean-check --self-test-report C:\Temp\chuba-offline-report.json
```

Используйте новую пустую папку профиля. Диагностика проверяет Sharp, наличие FFmpeg,
сегментацию и настоящий CPU-инференс всех четырёх вспомогательных моделей, записывает
пути использованных файлов и результат в JSON, затем закрывает приложение. Нормальный
пользовательский профиль не меняется. Проверка не скачивает файлы из сети.

## Повторение сборки

`npm run prepare:portable-models` подготавливает точные веса и проверяет контрольные
суммы. `npm run pack` делает то же самое перед сборкой. Веса и EXE не хранятся в Git;
конфигурация, проверяемые источники и сценарий подготовки хранятся. Пересборка EXE
разрешена только по прямой команде пользователя, затем обязательны verify, commit и push.

Это комплект для демонстрации. Коммерческий выпуск остаётся отдельным этапом дорожной
карты: полный пакет лицензий, исходники и сведения о сборке FFmpeg, аудит экспортов
весов и подпись приложения ещё требуют завершения.
