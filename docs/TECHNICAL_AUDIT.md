# Технический аудит после сценариев 1.7

Актуальное дополнение от 26 сентября: [проверенные исправления и расширенный план копилота](COPILOT_SCENARIOS_ROADMAP.md). Прямоугольник/лассо ниже добавлены в редактор **маски для удаления цвета**, а произвольное выделение пикселей, перенос и трансформации встроенного пиксельного редактора остаются отдельной крупной задачей.

Статус ниже означает наличие функции в текущем коде, а не обещание. Автопилот и инструменты сценариев уже работают с исходниками без записи поверх них.

| Область | Сейчас | Следующий шаг |
| --- | --- | --- |
| Атлас | Сетка и уплотнение по полкам (`tight`), ограничение размера, несколько страниц и проверка JSON. Это не MaxRects. | Добавить MaxRects с тестами на прямоугольники разных размеров и детерминированным результатом. |
| Поворот и края | В данных экспорта `rotated: false`; дублирования краевых пикселей нет. | Добавить независимые `rotate` и `extrude`, согласовать координаты с каждым экспортным форматом и проверить швы на реальном рендере. |
| Размеры и движки | Есть профили Chuba, Phaser 3, TexturePacker JSON, Unity и Godot. Размер каждого листа можно дополнить до степени двойки без сдвига кадров. Нет 9-slice, сжатых текстур, Spine/libGDX/Cocos/GameMaker/Defold. | Проверить импорт в выбранный движок; остальные профили — по реальному спросу. |
| Импорт/экспорт | Изображения, видео, листы и JSON; анимированный WebP. Нет нативного Aseprite или GIF. | Сделать совместимый импорт/экспорт после проверки лицензии и формата; не ставить Aseprite обязательной зависимостью. |
| Редактор | Есть карандаш, ластик, заливка, пипетка, палитра изображения, слои, видимость, блокировка, режимы смешивания, undo; выбранный объект можно перенести и масштабировать в общем окне. Нет выделения/лассо, волшебной палочки, симметрии, фигур, четырёхточечной перспективы и редактора нескольких кадров в одном полотне. | Первым добавить выделение объекта и ручное разделение слипшихся спрайтов; затем общие трансформации и фигуры. |
| Цвет и свет | Есть тонировка с сохранением альфы и светлотной структуры; это не перенос теней. Нет карты нормалей и скелетной анимации. | Отдельный эксперимент с оценкой нормалей, отделением запечённого света и единым источником для серии; результат обязательно сравнивать с оригиналом. |
| Сборка | Windows portable, крупный FFmpeg и `asar: false`. FFmpeg нельзя уменьшать или включать asar без проверки кодеков, путей к исполняемым файлам и запуска portable-версии. Подписи Windows нет. | Измерить время холодного запуска и список реально используемых кодеков, собрать маленький FFmpeg и повторить тест видео/экспорта/portable. Подпись требует сертификата владельца. |
| Поддержка кода | Модули и тесты добавлены, но `renderer.js` и `processor.mjs` остаются крупными. Обработка идёт через IPC в главном процессе Electron. Две копии автопилота служат интерфейсу и Node, их надо держать согласованными. Английский перевод частичный. | Выделить общие правила автопилота, затем очередь обработки в worker/utility process с отменой и прогрессом; добавить UI-тесты сценариев и завершить локализацию. |

Приоритет следующей итерации: **MaxRects + extrude**, затем **ручное выделение/разделение объектов**, затем **worker для длительных задач**. Поворот кадров включать только вместе с поддержкой во всех форматах экспорта. Aseprite/GIF и дополнительные движки добавлять по проверенному сценарию импорта/экспорта. Настоящее переосвещение — отдельная исследовательская функция; тонировку сохранять как простой предсказуемый инструмент.
