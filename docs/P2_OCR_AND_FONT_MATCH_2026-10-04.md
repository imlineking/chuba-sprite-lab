# Локальное распознавание и работа с надписью

OCR: в «Пиксели и текст» выделить надпись → «Распознать надпись» → язык → распознать → исправить результат → «В текстовый слой» → применить. Уверенность — значение Tesseract, не обещание безошибочности. Ничего не отправляется во внешний сервис; данные английского и русского включены в vendor/ocr и будущую упаковку. Остановка прерывает изолированный исполнитель.

Похожие шрифты: выделить одну строку на ровном фоне, ввести её точный текст (до 80 знаков), запустить подбор. Сравниваются формы и пропорции; 5 кандидатов имеют нужные символы по проверке Chromium с разными запасными шрифтами. Это локальное ранжирование, не гарантированная идентификация. Кнопка обновления перечитывает установленные шрифты без перезапуска.

Замена запечённой надписи: явная маска старых букв на активном пиксельном слое → соседний фон или LaMa → предпросмотр → применение → новый текстовый слой. На ровном фоне соседнее заполнение не размывает исходные пиксели за маской. LaMa может приблизительно достроить текстуру; скрытые детали не считаются точно восстановленными. Альфа сохраняется, прозрачные пиксели не становятся чёрными донорами. Общее размещение по кадрам будет связано с редактором серии.

Проверки: OCR на латинице и кириллице, маска и неизменность RGBA вне неё, ранжирование формы, предпросмотр без записи, undo/redo. Проверка реального Electron из исходников: OCR 95% на контрольной надписи, ручная коррекция, текстовый слой, 5 кандидатов (Arial первый), удаление/отмена/повтор, Призма/Фарфор и окно 1024×768. Источник сохранён. Доказательства: `.diagnostics/p2-ocr-ui-03/report.json` и снимки рядом.

Зависимости сверены с официальными [API Tesseract.js](https://github.com/naptha/tesseract.js/blob/master/docs/api.md) и [локальной установкой](https://github.com/naptha/tesseract.js/blob/master/docs/local-installation.md). `npm audit` после обновления транзитивного http-cache-semantics: 0 известных уязвимостей. EXE не пересобирался.
