# P1: размер и обрезка группы PNG

2 октября 2026. Реализовано в исходниках 1.8.2; EXE этим этапом не пересобирался.

## Пользовательский путь

Загрузить PNG → открыть обработку группы → раскрыть «Размер и обрезка PNG» → выбрать текущий файл, выделенные или все → обновить просмотр → применить → сохранить PNG. Ctrl+Z отменяет применение всей группы. Изменение размера сбрасывает устаревший просмотр и отключает применение до нового расчёта.

| Режим | Результат |
| --- | --- |
| Исходный размер | Геометрия не меняется. Этот режим включён по умолчанию. |
| Убрать прозрачные поля | Обрезка по всем пикселям с ненулевой альфой без масштабирования. Белый материал и полупрозрачные детали учитываются как объект. |
| Вписать в кадр | Точный W×H, сохранение пропорций, прозрачные поля, размещение по центру. |
| Заполнить и обрезать | Точный W×H, сохранение пропорций, обрезка выступающих краёв по центру. Предупреждение появляется в результате. |
| Растянуть | Точный W×H с независимым изменением ширины/высоты. Изменение пропорций явно обозначено. |

Размеры: целые 1–4096 px. Для подгонки можно убрать исходные прозрачные поля либо масштабировать весь исходный холст. Интерполяция — nearest без сглаживания для пикселей или Lanczos3 для плавной графики. Настройки не меняют исходные файлы.

Общая функция image-geometry.mjs используется быстрым просмотром и полным обработчиком. Геометрия выполняется после очистки, перед пикселизацией на конечной сетке. Дальнейшие цветовые настройки сохраняются. Настройки imageGeometry проходят строгую проверку в рецепте JSON: неверные размеры, неизвестные режимы/параметры и интерполяция отвергаются.

Применённый PNG становится текущим результатом; сохранение не запускает его подгонку и пикселизацию повторно. Упаковка уже проверенных изображений также отключает повторную геометрию. Это не завершение нового общего маршрута сборки единого спрайт-листа и полного редактирования метаданных атласа.

## Проверка

- Полный npm run verify: 315 тестов, 314 успешно, 1 пропущен, ошибок нет.
- Отдельный прогон геометрии и рецептов: 21 тест, без ошибок.
- Обрезка сохраняет RGB/альфу каждого пикселя объекта, в том числе белого и частично прозрачного.
- Вписывание проверено с прозрачными полями, сохранением исходного холста и размером 1×1. Заполнение/растяжение обозначают потерю краёв или изменение пропорций.
- Реальный Electron: группа из двух PNG 64×48 → вписывание 32×24 вместе с пикселизацией → применение → сохранение → отмена. Размеры и сохранённые пиксели точно совпали с просмотром; исходные PNG не изменились.
- Геометрия раскрытого окна проверена на 1024×768 в светлой и тёмной темах: сравнение видно, кнопки доступны, горизонтального переполнения нет.
