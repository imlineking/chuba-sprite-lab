# Skills и скрипты для Sprite Lab

Проверено 4 октября 2026. Skills — инструкции для ассистента; они сами не становятся функциями EXE и не улучшают маску нейросети. Совместимость здесь определяется доступными инструментами и средой Windows/Electron, а не названием модели. Ничего нового этим поиском не установлено.

| Кандидат | Польза | Совместимость и решение |
| --- | --- | --- |
| Уже доступный `frontend-design` | Геометрия панелей, состояния, удобный маршрут задачи | Применяется с приоритетом пользовательских тем Призма/Фарфор и MEMORY.md. Общие дизайнерские рекомендации не заменяют реальную проверку. |
| [OpenAI playwright-interactive](https://github.com/openai/skills/tree/main/skills/.curated/playwright-interactive) | Постоянная сессия Electron, реальные клики, снимки, проверки обеих тем | Skill прямо требует `js_repl`; такого инструмента в текущей сессии нет. Установка одного SKILL.md это не исправит. Подходит после появления нужного runtime. Сейчас проектные CDP-проверки выполняют эту задачу без новых зависимостей. |
| [OpenAI playwright](https://github.com/openai/skills/tree/main/skills/.curated/playwright) | Проверка веб-интерфейсов через CLI | Node/npm/npx доступны. Комплект содержит shell-обёртку; Bash не обнаружен в PATH, значит прямой Windows-маршрут надо отдельно проверить. Для текущего Electron проекта не даёт преимущества перед существующими сценариями CDP. |
| [OpenAI gh-fix-ci](https://github.com/openai/skills/tree/main/skills/.curated/gh-fix-ci) | Разбор провалившихся GitHub Actions по логам | `gh` установлен. Полезен при фактической ошибке CI и доступной авторизации; не нужен вместо локального verify. |
| [OpenAI security-best-practices](https://github.com/openai/skills/tree/main/skills/.curated/security-best-practices) | Проверка JavaScript/Python кода при отдельном аудите | Языки подходят. Полезен для IPC, путей и импорта файлов; специализированную проверку Electron всё равно нужно проводить по его модели процессов и разрешений. |
| [OpenAI cli-creator](https://github.com/openai/skills/tree/main/skills/.curated/cli-creator) | Общий интерфейс команд и JSON для автоматизации | Node и Python доступны. У нас CLI уже есть, поэтому не создавать вторую конкурирующую оболочку. Использовать только при расширении действующего контракта. |
| [Aseprite CLI](https://www.aseprite.org/docs/cli/) | Внешний эталон нарезки, палитр и PNG/JSON, пакетные Lua-скрипты | Это отдельная программа, не skill и не компонент нашего EXE. Имеет смысл для будущих тестов совместимости при доступном Aseprite; не добавлять его в portable без отдельного решения. |

## Практическая очередь

1. Продолжить использовать `frontend-design`, текущие Node-тесты и `scripts/verify-image-workflow-ui.mjs`.
2. Для первого блока P2 добавлен `scripts/verify-color-styles-ui.mjs`: реальный PNG, живой просмотр, Apply/Cancel/Undo, пакет, сохранение без повторного стиля, обе темы и окно 1024×768.
3. Для следующих блоков расширять эти проверки: одна библиотека алгоритма для preview/export, RGBA-проверка прозрачности, PNG/JSON roundtrip, отмена и сравнение сохранённых пикселей.
4. `playwright-interactive` — наиболее полезное дополнительное средство при появлении `js_repl`. Остальные кандидаты подключать по задаче, без накопления навыков и тяжёлых зависимостей.

Каталог проверялся официальным `skill-installer/scripts/list-skills.py --format json` из `openai/skills`; требования просмотрены в текущих SKILL.md. Статус `installed:false` этого скрипта означает отсутствие в пользовательской папке skills: уже доступный навык из плагина может храниться в другом месте.
