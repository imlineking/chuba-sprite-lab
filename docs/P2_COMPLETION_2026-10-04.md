Отчёты находятся в этой папке; повторяемые сценарии — в `scripts/verify-*-ui.mjs`, результаты живых прогонов — в `.diagnostics`. Полный `npm run verify` включает lint и последовательные функциональные тесты. Проверки выполняют реальную обработку и сравнение RGBA/метаданных, а не только наличие элементов.

Финальный прогон: 379 тестов, 378 успешны, ноль ошибок, один пропущен. Пропущен дополнительный совместный прогон LaMa/Real-ESRGAN/RIFE/Depth: для него требуется явный `CHUBA_AUX_MODELS`. Живые проверки каждого нового блока P2 перечислены выше. Лог: `.diagnostics/p2-final-verify.log`. Проверка production-зависимостей `npm audit --omit=dev` — ноль уязвимостей.

## Практические пределы

- Восстановление по соседним пикселям/LaMa приблизительное. Подбор шрифта предлагает кандидатов. Белые детали, тонкие края и неоднозначные маски требуют просмотра.
- GIF ограничен палитрой и шагом времени; APNG сохраняет RGBA. В .aseprite тайловые слои, сложные группы и ICC требуют PNG + JSON.
- BC3 меняет цвета/альфу; PNG сохраняется. 9-slice требует регулярного листа без поворота/обрезки.
- Индексируется каждый слой; итоговый PNG — RGBA-композиция. Полного редактора карт нет. Произвольные/перспективные преобразования остаются дополнительным этапом после базового P2.

## Отдельная приёмка выпуска

Чистая Windows без сети, настоящие два монитора/DPI, измерения упаковки/FFmpeg, полный лицензионный комплект, сертификат подписи и приёмник обратной связи относятся к выпуску. Они не объявлены пройденными. Новая EXE-сборка — только по прямой команде; после неё verify → commit → push. P3 — отдельные эксперименты с ИИ, их не включаем молча в базовый P2.
