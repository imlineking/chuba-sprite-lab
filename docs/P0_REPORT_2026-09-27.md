## Исправления

### Пакетная обработка

Автоочистка открывает сравнение исходника и результата до записи пользовательских PNG. Область действия: текущий, выбранные в списке или все. Есть результаты/ошибки по файлам, повтор только ошибок, продолжение оставшихся, остановка и восстановление черновика из сохранённого просмотра. Успешные файлы не перерабатываются при повторе ошибки.

Очистка применяется к проекту одним шагом истории. Ctrl+Z отменяет весь применённый пакет. Принятая очистка не выполняется второй раз на уже очищенном PNG при просмотре/экспорте; новые маски и изменённые настройки остаются доступны. Цветовые фильтры и пикселизация не запекаются скрыто в обычный пакет очистки.

Сценарий пакетного PNG + JSON также сначала показывает очистку. После проверки сохраняются отдельные наборы. Повтор сохранения обрабатывает только неудачные или ещё не сохранённые наборы. Экспорт не изменяет исходные файлы; отмена правок проекта не удаляет сохранённые экспорты. Промежуточные изображения хранятся в локальном кеше приложения, не в пользовательской папке результатов.

### Переносимость проекта

Вместе с `.cslab` в соседней `.assets` сохраняются оригинальные изображения/видео, изменённые кадры, маски, привязки и ресурсы именованных анимаций. На диске пути относительные; при открытии разрешаются от каталога проекта. Для переноса копировать `.cslab` и его `.assets` вместе; `.bak` — предыдущая сохранённая версия.

JSON записывается через уникальный временный файл и атомарное переименование. Ресурсы именуются по содержимому, проверяются при копировании и не перезаписывают старую версию. Блокировка защищает одновременную запись; конфликт с другой версией требует открыть свежий проект или сохранить копию. Незавершённая блокировка после сбоя восстанавливается. Повреждённый JSON может быть восстановлен из `.bak`.

Пропавшие файлы больше не удаляются из списка молча: программа предлагает указать замену. Порядок и индексы кадров сохраняются. Отмена выбора прекращает открытие проекта.

Пакетный просмотр использует обе утверждённые темы. Нижняя панель пиксельного редактора проверена с длинным статусом и открытой формой цвета.

### Что показало качество вырезки

На контрольном изображении белых цветов с известной исходной альфой:

| Фон и инструмент | Совпадение маски (IoU) | Сохранение белых деталей |
| --- | ---: | ---: |
| Белый фон, удаление по контуру | 81,42% | 16,41% |
| Белый фон, удаление всего белого | 78,76% | 0% |
| Белый фон, U²-Net small | 69,74% | 99,65% |
| Белый фон, BiRefNet Tiny | 97,29% | 99,72% |
| Клетка, инструмент удаления клетки | 88,02% | 31,74% |
| Клетка, BiRefNet Tiny | 97,32% | 99,63% |

IoU — отношение пересечения масок к их объединению. Эти числа относятся к одному контрольному изображению; они не являются универсальной точностью моделей. Сохранение деталей проверяется отдельно от удаления фона: модель может сохранить цветы, но оставить часть фона.

Автоплан выбрал ToonOut для сложной ветки и «БЗЗЗ!». На цветной подложке у ветки остаются отдельные белые фрагменты, у комикса — спорные просветы рядом с молниями. Идеальной маски не обещаем. Проверка после модели теперь показывает коды `white-regions-to-review` и `residual-checker` с пояснением: похожая область может быть частью рисунка. Предупреждение не меняет пиксели. Эталонные оригиналы и игровые файлы не изменялись.

Портрет проверен как вырезка и пиксельный фильтр; художественной перерисовкой это не называется. Проверены также смешанный атлас, видео, анимация клубка, цикл бумаги, режимы пиксельного фильтра и специализированные этапы LaMa/RIFE/Real-ESRGAN/Depth. Наличие одинаковых PNG при одинаковых настройках конвейера не доказывает, что Qwen/Gemma выбирают план лучше.

## Границы и следующая очередь

- Перед выпуском нужна реальная смена двух физических мониторов с разным DPI и чистая Windows без сети. Эмуляцию нельзя считать выполнением этих аппаратных испытаний.
- Качество светлых деталей/просветов и автоматический выбор альтернативной маски — первая задача P1. Результат автоматической вырезки нужно сравнивать перед применением.
- Активные пакетные просмотры сохраняются для восстановления; очистка неиспользуемого кеша по сроку хранения записана в P1.
- Самодостаточный один EXE, новый комплект и проверка всех функций на новой машине не выполнены: действует запрет пересборки.
- Крупные функции редактора, MaxRects/extrude, фоновые workers и художественный портрет не входят в закрытый P0. Очередь и предварительные активные часы — [ROADMAP_CURRENT_HOURS.md](ROADMAP_CURRENT_HOURS.md).

Локальные доказательства: `.diagnostics/p0/verify-final.log`, `live-assets/report.json`, `processing/report.json`, `ui-evidence/report.json`, `desktop-final.json`; там же реальные PNG и снимки интерфейса. Генерируемые изображения и диагностические профили не добавляются в Git.

Окно ошибки Electron во время ограниченного проверочного запуска было связано с отказом Windows создать дочерний процесс (`0x5`, затем аварийное завершение). Проверки повторены с разрешённым запуском процессов. Игра и существующий EXE этим запуском не менялись.
