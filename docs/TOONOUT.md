# ToonOut: локальная вырезка сложной графики

27 сентября 2026. Подключён в исходный конвейер ONNX Runtime, Python пользователю не нужен. Включение в конфигурацию ресурсов не означает пересборку прежнего EXE.

## Где используется

- Автоочистка сложной растительности с запечённой клеткой и остатками фона, включая частично прозрачные исходники.
- Сложная комиксная графика с тонкими цветными границами на однотонном фоне, как «БЗЗЗ!».
- Ручной выбор ToonOut в модели выделения; выбранная модель не подменяется быстрым удалением цвета.

Автовыбор консервативный: нативные замеры, более 400 000 пикселей, плотность сильных цветных границ ≥ 8,5%; подтверждённая клетка либо однотонный фон с большим разнообразием цветов/заливок. Это проверяемая эвристика, не распознавание смысла рисунка. Порог требует дальнейшей проверки на большом наборе.

Подготовленная после нарезки маска не выделяется повторно. Для простых цветов, обычных портретов и уже чистой прозрачности остаются прежние методы. В автоматическом плане после ToonOut нет повторного удаления шахмат. Изменения применяются через существующие отменяемые операции и предварительный просмотр. Модель не стилизует и не рисует портрет.

## Происхождение

- Официальные [веса ToonOut](https://huggingface.co/joelseytre/toonout), revision `cbf720eca394edcde66b861a8a8c20fbabe9c748`.
- SHA-256 PyTorch checkpoint: `8c7f8a0bc24400f4caade76622f75ff22ca1e93e169add9d2b70093e2487fbe5`.
- [Официальный код](https://github.com/MatteoKartoon/BiRefNet), commit `ba5d19a7bf16b1ea7746bb9e9bec83d97dad9709`.
- ONNX: `toonout.onnx`, 929 574 435 байт, SHA-256 `b9eec8cc66541c9a55a69986d3b0ca44150cf19ed399f42022ee81edf528f48a`.
- MIT: текст в `models/ToonOut-LICENSE.txt`. Данные для обучения имеют отдельную лицензию; датасет не распространяется с программой.

Экспорт разработчика: `python scripts/export-toonout.py <official-repo> <verified-checkpoint.pth> <app-root/models/toonout.onnx>`. Проверены Python 3.12, torch 2.14.0+cpu и onnx 1.23.0. Opset 19, стандартный DeformConv; вход ImageNet RGB 1024², единственный выход sigmoid alpha. Подложка прозрачных пикселей белая; один проход сохраняет общий контекст. Вероятности не растягиваются min/max. Модель загружается при первом использовании, а не при запуске программы.

`prepare-portable-models` принимает только проверенный локальный экспорт; без него сборка останавливается с объяснением. Случайный файл или чужое зеркало не подставляется. Новый EXE по этому запросу не собран.

## Проверка

На одном и том же тензоре ONNX CPU и PyTorch: средняя ошибка 6,90e-8, максимальная 0,0001323; ни один из 1 048 576 пикселей не изменил сторону порога 0,5. Это проверка корректности переноса, а не оценка качества сегментации.

Шесть живых/контрольных случаев: БЗЗЗ, ветка, белые цветы, контрольный белый фон, контрольная клетка, фото. При текущем Sharp-пересэмплировании контрольный IoU 0,9693 (белый), 0,9650 (клетка). У Tiny на контрольных цветах преимущества ToonOut нет. На сложных ветках/комиксе визуально полезнее. Локальный CPU-прогон: примерно 12 секунд на файл вместе с замерами; первый загрузочный этап ~2,7 с. Это один прогон, не универсальная оценка скорости.

Ограничения: тонкие линии могут теряться, часть белого фона остаётся; требуется проверка на зелёной/чёрной подложке. Нет ручного эталона сложных масок, поэтому оценка 4/5 субъективная. DirectML на этой машине отдельно не сертифицирован; автоматический провайдер пробует CPU при невозможности загрузки DML.
