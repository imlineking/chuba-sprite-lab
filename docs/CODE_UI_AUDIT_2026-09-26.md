### Визуальная оценка фильтров

На той же фотографии clean не изменился. Shaded лучше сохраняет оттенок кожи; lineart теперь показывает глаза, линии лица, воротник и складки вместо почти пустого силуэта. Ориентировочная авторская оценка: shaded **3/5**, lineart **3–3,5/5**. Это субъективная оценка одного портрета, не средняя точность модели. Оба режима остаются арифметическими фильтрами; полноценная художественная перерисовка ими не реализована.

Контактный лист до/после: `workspace-style-fixes-2026-09-26/style-before-after.png` в тестовой папке. Старая оценка в отчёте обработки описывает состояние до этих исправлений.

## Знакомство и имя пользователя

При первом запуске появляется **«Привет, давай знакомиться!»** с полем имени. Настройки доступны через шестерёнку в шапке.

- Введённое имя сохраняется локально и сразу меняет приветствие настольного копилота.
- Пропуск, крестик, щелчок вне окна и Escape при первом запуске завершают знакомство и используют имя текущей учётной записи.
- Из автоматического имени берётся **только первое слово**, без фамилии: `Dmitriy Demidenko` → `Dmitriy`. Вручную введённое имя сохраняется как написано.
- В настройках отмена/закрытие не сохраняют набранные изменения. Пустое поле + сохранение возвращают автоматическое имя.
- При недоступном имени используется общее приветствие. Положение копилота хранится отдельно от имени.
- Полный перезапуск подтвердил сохранение имени и отсутствие повторного окна знакомства; отдельная проверка подтвердила текст **«Привет, Дмитрий»** в настоящем облаке.

**Ограничение Windows на этом ПК:** доступные локальные источники имени текущего SID не вернули отображаемое `Dmitriy Demidenko`; программа получает технический логин `User`. Добавлены безопасные попытки прочитать FullName и DisplayName текущего пользователя, но нельзя заявить, что автоматическое определение здесь исправлено полностью. Ввод имени решает обращение; дополнительный официальный способ чтения отображаемого имени Microsoft-аккаунта остаётся отдельным пунктом дорожной карты. Имя компьютера и имя владельца Windows не используются.

## Воспроизведение без пересборки

Из корня проекта, с доступными установленными зависимостями и оригинальными тестовыми ассетами:

```powershell
node scripts/audit-workspace-ui.mjs <output-folder> <game-root>
node scripts/verify-copilot-ui.mjs <output-folder>
node scripts/verify-pixel-style-fixes.mjs <prepared-portrait-png> <previous-benchmark-folder> <output-folder>
$env:CHUBA_AUX_MODELS = Join-Path (Get-Location) 'models'
npm run verify
```

UI-скрипты создают отдельные профили и завершают собственный Electron. Реальные пользовательские настройки и ассеты не меняются.
