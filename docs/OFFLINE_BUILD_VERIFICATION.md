# Проверка portable-комплекта — 26 сентября 2026

## Текущий комплект: 1.8.0

Запуск: `portable/Chuba Sprite Lab.exe`. Копировать нужно **всю папку `portable`**.

- Размер комплекта: **4 995 876 346 байт**, 531 файл (около 5,00 GB / 4,65 GiB).
- В комплекте 14 работающих ONNX-моделей. SHA-256 и размер каждого файла сверены
  с `portable/resources/models/bundled-models.json`.
- EXE: **246 059 008 байт**, ProductVersion **1.8.0.0**;
  SHA-256: `22f728eccb851b691d7da14259f3100fc286007fcd1313e679d405a325ecd3f9`.
- `npm run verify`: **210 тестов, 210 пройдено, 0 ошибок, 0 пропусков**.
  Реальный конвейер LaMa → Real-ESRGAN → RIFE → Depth проверен с отсутствующим
  пользовательским кешем; исходные изображения не менялись.
- Сам portable запущен с `--self-test --self-test-all-models` и новым профилем:
  **17 проверок пройдено**, включая Sharp, FFmpeg и инференс всех 14 моделей.
  Пути весов указывают только на `portable/resources/models`.
  Дополнительно в профиль положен заведомо повреждённый `u2netp.onnx`:
  он не перекрыл проверенную модель комплекта.
- Native-проверка `--desktop-probe` подтвердила отдельные окна помощника,
  перетаскивание, отсутствие файлового drag-and-drop, сохранение позиции после
  пересоздания окон, независимость от сворачивания главного окна, переход к
  сценарию, анимацию текста загрузки. Приветствие использует учётную запись Windows.
- Визуально проверены тёмная и бело-серая темы на игровом листе клубка,
  переключение вкладок и окно «О программе». В анимации видны обе оси бирюзовой
  сетки с шагом 50 px; направляющие не относятся к экспортируемым изображениям.
  Кнопки кадров не выходят за контейнер; окно «О программе» не прокручивается.
- Актуальная сборка хранится в `portable`. Старые `dist`, `release` и заменённые
  portable-комплекты сохранены в игнорируемой `.build-archive` для восстановления.

Проверки выполнены на этом Windows-компьютере. Отдельный физический компьютер
пока не проверялся. Скачивания не являются этапом обработки: все подключённые
модели уже поставляются с программой. Обновления и внешние онлайн-редакторы требуют
интернета; встроенные операции работают локально. Каталожные этапы SAM/ViTMatte,
которые ещё не реализованы, не входят в число 14 работающих моделей.

## Историческая проверка: 1.7.0

Версия приложения: 1.7.0. Файл: `dist/Chuba-Sprite-Lab-portable.exe`.

- Размер: **432 915 766 байт** (412,86 MiB).
- SHA-256: `dc397c5eacdbb051fd8e7707f717c3c5075cb2e18448599d6fe10d1dd249602f`.
- Финальный `npm run verify`: **206 тестов, 206 пройдено, 0 ошибок, 0 пропусков**.
- Реальный тест конвейера включён через `CHUBA_AUX_MODELS` с отсутствующей папкой
  пользовательских моделей: поиск успешно использовал встроенные веса из проекта.
  LaMa, увеличение Real-ESRGAN, интерполяция RIFE и карты глубины завершили один атлас;
  два кадра превратились в три, FPS удвоился, исходники остались неизменными.
- Сам portable EXE запущен с `--self-test --self-test-all-models` и новым пустым
  профилем. Код выхода **0**, JSON-отчёт `ok: true`. Sharp, FFmpeg, U²-Net small,
  LaMa, RIFE, Real-ESRGAN anime 6B и Depth Anything V2 Small прошли диагностику.
  Пути всех моделей указывали на временную папку распаковки EXE, а не на исходный
  проект или папку ранее скачанных моделей. Диагностика модели не скачивает.
- Визуально проверено окно моделей в упакованном приложении: встроенные модели
  отмечены «в комплекте», доступны для проверки запуском, кнопки удаления не показаны.
  Устаревший текст о необходимости загрузки заменён описанием офлайн-комплекта.
- Исправление EPIPE проверено повторным запуском из закрывающего канал вывода shell:
  диагностика завершилась без оставшегося процесса и окна ошибки.

Проверка выполнена на текущем Windows-компьютере с чистым диагностическим профилем;
отдельный физический компьютер пока не проверялся. Инференс подтверждает работоспособность
контрактов моделей, но не гарантирует качество результата на произвольной иллюстрации.
Подготовка коммерческого выпуска и лицензий остаётся в дорожной карте.

Порядок повторной диагностики описан в [OFFLINE_DEMO.md](OFFLINE_DEMO.md).
