# Унификация инструментов и начало P1

2 октября 2026. Изменения в исходниках 1.8.2. Существующий EXE этим этапом не пересобирался.

## Принятое решение

По визуальной оценке пользователя после сравнения 35 композитов на семи фонах ToonOut выбран единственной нейросетевой моделью вырезки. Численные сравнения с исходной альфой и предыдущие роли альтернатив сохранены в исторических отчётах; это решение не означает гарантии идеальной маски для любого изображения.

Активный каталог и комплект следующей сборки содержат пять моделей:

| Функция | Исполнитель |
| --- | --- |
| Вырезка сложного объекта | ToonOut |
| Дорисовка области фона | LaMa |
| Промежуточные кадры анимации | RIFE |
| Увеличение изображения | Real-ESRGAN |
| Карта глубины | Depth Anything V2 Small |

Локальная вырезка ровного белого, чёрного, зелёного, маджента и выбранного пипеткой цвета сохранена. Чёрный фон имеет варианты с защитой контура и без неё. «Подорожник» восстанавливает повреждённый объект и сохраняет свою маску при последующей локальной очистке; повторное выделение ToonOut доступно отдельным выбором. Пикселизация, цвет, кисти, геометрия кадра и экспорт не требуют дополнительных моделей.

Убраны из активного каталога и упаковки U²-Net, Silueta, IS-Net General/Anime, BiRefNet Tiny/General/HR/Portrait, ViTMatte и SAM. Старые сохранённые идентификаторы этих моделей переводятся в ToonOut. Неизвестный идентификатор вызывает ошибку; отсутствующий ToonOut не заменяется случайной моделью. Ошибка GPU может вызвать один повтор ToonOut на CPU.

Десять прежних файлов весов и их контрольные суммы перенесены из models в локальный архив .diagnostics/retired-matting-models-2026-10-02. Общий объём весов: 4 023 725 848 байт, около 3,75 GiB. Это уменьшение активного комплекта, а не освобождение места на диске: архив сохранён. Ранее выпущенный EXE остаётся с прежним составом. Старые чистые функции тензоров оставлены для проверки исторических контрактов, но не включают удалённые модели в каталог.

## Первый завершённый шаг P1

В окно обработки группы PNG добавлена явная «Пикселизация после очистки»: блок 2–32 px, палитра 8/16/32/64/128 цветов, без дизеринга, Bayer 4×4 либо Флойд — Стейнберг. Она выключена по умолчанию, не наследует случайные настройки анимации и работает с текущим файлом, выделенными файлами или всей группой. Изменение настройки сбрасывает устаревшие результаты просмотра.

Маршрут: выбрать очистку либо восстановление → настроить цвет и при необходимости пикселизацию → обновить просмотр → применить выбранные → сохранить PNG. Подложка проверки не запекается в PNG, холст сохраняется, применение отменяется одной операцией. Это фильтр исходной графики; художественная генерация новых деталей не заявляется.
