# Кадры, кисти и фигуры в редакторе

Открытие редактора для анимации загружает серию в один документ. Панель под холстом: предыдущий/следующий кадр, выбор номера, длительность 10–10000 мс, воспроизведение, соседние кадры. История общая; отмена возвращает кадр, на котором сделана правка. Применение записывает PNG и редактируемые слои для всей серии, сохраняет длительности в проекте. При разных размерах исходников общий холст дополняется прозрачностью справа/снизу, без растяжения; лимиты — 512 кадров и 256 МБ исходных пикселей.

Текст: «Надпись на всю серию» переносит точные пиксели, шрифт и координаты выбранного текстового слоя во все кадры. Дальнейшая правка общего слоя распространяется по серии; переносимый проект сохраняет связь. Отмена — одна операция. Старые нарисованные буквы удаляются явной маской отдельно для каждого кадра: автоматический перенос маски между различающимися рисунками не выполняется.

Кисть: числовой размер 1–64 px, [ / ] для шага; квадрат/круг, жёсткость 0–100%, непрозрачность 0–100%, симметрия X/Y/обе оси, Pixel Perfect для 1 px. Покрытие курсора соответствует той же функции, что рисует мазок. Полупрозрачность внутри одного мазка не накапливается при пересечении собственных штампов. Мазок объединён в одну отмену. Ластик уменьшает альфа-канал, не добавляет чёрные пиксели.

Линия, прямоугольник, эллипс: перетянуть от начала к концу, увидеть просмотр, отпустить для применения. Фигуры используют параметры кисти, ограничиваются выделением и отменяются целиком. Отражение X/Y и поворот ±90° работают с выделенными пикселями. Поворот с обрезанием холстом отказывается от записи и объясняет причину. Произвольная/перспективная трансформация остаётся дополнительным исследовательским подэтапом, отдельно от базового набора P2.

Проверены прозрачность и перекрытия мазка, общая отмена, маска, точные RGBA при отражении, история фигур, длительность и соседние кадры, общий текст после повторного открытия. Реальный Electron: два кадра белых цветов, указатель рисует полупрозрачный мазок, одна отмена возвращает оригинал; правки второго кадра не теряются при смене; общая надпись и 240 мс восстановлены после сохранения; playback, обе темы и 1024×768. Источник не изменён. Доказательства: `.diagnostics/p2-editor-series-ui-02/`.
