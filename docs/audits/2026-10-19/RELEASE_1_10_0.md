## Проверки после сборки

- `npm run verify`: **524 теста, 523 успешных, 0 ошибок, 1 пропуск**, 139,4 с. Пропуск относится к отдельному тяжёлому тесту вспомогательных моделей; они отдельно проверены самим EXE.
- Самодиагностика фактического однофайлового EXE: Sharp, FFmpeg и реальные вычисления **ToonOut, LaMa, RIFE, Real-ESRGAN, Depth Anything V2** завершились успешно. ToonOut использовал DirectML. [Машинный отчёт](release-self-test.json).
- Все **154 файла `src`** в распакованном приложении побайтно совпали с рабочими исходниками; версия, main и зависимости package.json также совпали. Development-метаданные package.json штатно убирает упаковщик. [Сверка](release-bundle-equality.json).
- В фактическом EXE: вход в новую сцену из конвейера, импорт PNG через IPC, изменение параметра, undo/redo, движение камеры, остановка RAF после закрытия, обе темы, отсутствие renderer-исключений. Диалоги экспорта/открытия сцены проверены отдельным исходным стендом, а не этим EXE-прогоном. [Отчёт EXE](release-parallax-ui.json).
- В фактическом EXE на белом цветке: очистка, цвет, Подорожник, применение/сохранение/undo, квадратная кисть 1 px, пикселизация, готовые лист/атлас с белым фоном и страницами, слой из выделения, сохранение метаданных. Проверены обе темы при 1360×900, 1280×720, 1024×768. Исходник не изменён; сохранённые пиксели совпали с выбранным просмотром; renderer-исключений нет. [Отчёт](release-image-workflow-ui.json).
- Расширенные пакетные сценарии подтверждения палитры, пипетки и геометрии проверены исходным стендом, а не повторно в EXE. Оба стенда и происхождение свидетельств описаны в функциональном разборе. Пагинация готового листа проверяется на двух отдельных фикстурах с отключённой дедупликацией.

Очистка белого цветка остаётся результатом для просмотра, а не эталонной маской: модель изменила альфу 12 170 пикселей светлых областей, RGB-доводка — 2 297 пикселей кромки. UI явно сообщает необходимость проверки белых деталей. Не заявляются идеальная вырезка любого файла, испытание на чистой офлайн-Windows или физическая смена мониторов с разным DPI.

## Очистка

После проверок подтверждено удаление **129 объектов верхнего уровня, 14 902 835 319 байт** (14,9 ГБ / 13,9 ГиБ):

- промежуточная `.build` и архив прежнего portable EXE;
- два старых самостоятельных EXE 1.8.2 из точно определённой папки предыдущих сборок;
- три старые распакованные копии 1.8.2/1.9.0;
- 122 тестовых профиля/кеша внутри `.diagnostics`.

Сохранены новый EXE и текущая распакованная копия, исходники/Git, модели, runtime, зависимости для разработки, ресурсы/пресеты и итоговые отчёты/снимки. Пользовательские проекты и файлы игры не очищались.

**Остаток:** три старых каталога распаковки 1.8.2 в AppData (в сумме 14 095 964 444 байт). Первый вызов удаления вернулся без ошибок, но проверка обнаружила каталоги на месте. Повторное удаление отклонила автоматическая проверка безопасности инструмента без более конкретного объяснения. Обход не предпринимался; эти байты исключены из числа удалённых. Контрольный размер/хеш EXE и цели ярлыков после очистки: [release-artifact.json](release-artifact.json). GitHub Release с бинарным файлом не публиковался: отправка исходников в Git и публикация EXE — разные действия.
