# Функциональный разбор Sprite Lab — 19 октября 2026

Разбор ниже выполнен сначала в рабочих исходниках. Затем по прямой команде пользователя собран **EXE 1.10.0**: он включает описанные изменения, основной ярлык и `Start Sprite Lab.bat` открывают его. Для разработки — **`Start Sprite Lab Source.bat`** или `npm start`. Проверочный запуск нового BAT подтвердил корень рабочего проекта и `ok: true`. Итоговые проверки упакованного приложения и очистка — [в отчёте выпуска](RELEASE_1_10_0.md).

## Что проверено и изменено

Цель пользователя: загрузить ресурсы, получить пригодный для игры результат без изучения множества похожих инструментов. История проблем: молчаливое совпадение входа/выхода, потеря белых деталей, светлая/чёрная кромка, слишком маленький просмотр, повторная очистка готового материала, неудобные кисти, несвязанные помощник/чат и разрыв между проверкой/экспортом.

При старте уже существовали незакоммиченные изменения альфа-остатков, планировщика и ограниченной маски ToonOut. Они сохранены; снимок исходного diff и двух новых файлов — `.diagnostics/functional-review-2026-10-19/preexisting*`. Эти изменения не выдаются за новую отдельную реализацию данного прохода.

## Референс и новая сцена

Реально открыт [V0ALLAX — Parallax Studio](https://v0.app/templates/v0allax-parallax-studio-cID2KCmpvaL) в браузере, включая встроенный редактор. Виден путь со слоями, источником картинки, якорями, положением и интенсивностью X/Y; описание также заявляет idle-анимации, смешивание/клип, responsive и React-экспорт. Последние заявления не означают, что весь их runtime проверен нами.

Взята **логика задачи**, не код/дизайн/ассеты: список слоёв с заднего к переднему, выбранный слой, числовые свойства, камера и автономная проверка результата. Сохранены Фарфор/Призма и существующая типографика.

Доступны до 32 слоёв, видимость, копия/удаление/порядок, якоря, X/Y, масштаб, поворот, непрозрачность, независимые коэффициенты параллакса, горизонтальный повтор, колебание с периодом 4 с, фон сцены, чёткие пиксели, undo/redo, камера перетаскиванием и воспроизведение. Формулы preview и экспорта — **одно ядро**.

«Сохранить сцену…» создаёт новую папку без перезаписи предыдущих результатов: исходные ресурсы, `scene.parallax.json`, `preview.html`, `runtime.js`, пояснение. Классический JS работает с `file://`, без веб-сервера и сети. Открытие JSON проверяет формат, размеры файлов, локальные относительные пути и реальные пути ресурсов; внешние URL и `../` отклоняются. PNG копируются без перекодирования.

Черновик сцены отделён от проекта студии; закрытие панели его не теряет. Завершение приложения учитывает несохранённую сцену. «Новая сцена» отменяется; неудачный импорт не заменяет существующие слои. После удаления ресурсы освобождаются, undo загружает их заново. Общий лимит 128 Мп проверяется до декодирования очередной пачки, не только по одной загрузке.

## Честные границы и следующая очередь

Это не полная реализация V0ALLAX: пока нет React/Next-компонента, гироскопа, blend/clip, эффектов отражения и движковых адаптеров сцены. Слои собираются вручную, а не генерируются одной depth-моделью. Текущая сцена сохраняется отдельным переносимым пакетом, ещё не внутри `.cslab`. Повтор X ограничен 513 отрисовками на слой; микроскопические тайлы и бесконечная игровая карта не являются проверенным сценарием. 128 Мп проверены граничными значениями метаданных, фактическое заполнение такой памяти не выполнялось.

RGB-контроль — ограниченная часть задуманного замкнутого цикла, не автоматическая художественная приёмка, не повтор сегментации и не генеративное восстановление. Снижение числа нейтральных пикселей само по себе не доказывает красоту контура: поэтому сохраняются кандидат, просмотр и отмена.

Далее по зависимости: (1) общий проект/сценовый JSON и выбранный движковый адаптер; (2) сравнение очистки на эталонных масках реальных веток/травы/белых цветов/грибов; (3) генеративное восстановление только после выбора допустимой модели, сохранения альфы/стиля и сравнительного результата. Исследовательские пункты не объявлены реализованными, новая модель без измеримого выигрыша не добавлялась.

После описанного разбора создан и проверен локальный EXE 1.10.0 вместе с сохранёнными предшествующими изменениями. GitHub Release не публиковался; отправка исходников в Git не является публикацией установочного файла. Финальный прогон после сборки: 523 успешных теста, 0 ошибок, 1 пропуск; отдельная диагностика EXE проверила все пять встроенных моделей.
