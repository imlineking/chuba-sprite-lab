# Этап 5 — рабочая версия, проигрыватель, проверка кадра

## Договор

Пользователь подтвердил следующий пакет: связать ручную студию с просмотром, проверкой и экспортом; затем добавить воспроизведение анимации и переход к проблемным кадрам. Сохранить темы Призма/Фарфор и короткую помощь копилота. Новых обращений к внешним моделям и независимому критику не было по действующему указанию пользователя. EXE не пересобирался.

## Реализовано

- Открытый результат связывается с конкретным источником студии. Подпись параметров отличает изменение пикселей/маски/тайминга от смены выбранного кадра. Применённая в редакторе правка становится рабочей версией; просмотр выбранного кадра использует актуальный предпросмотр обработки, защищённый от устаревших асинхронных ответов.
- Копилот и главное действие предлагают применить рабочую версию. До пересборки старый отчёт не открывается как актуальная проверка. Результат пересобирается из источника студии и текущих операций, проверяется и экспортируется в отдельную папку; предыдущий экспорт сохраняется.
- Возврат в редактор сохраняет правки. Undo/redo обновляет признак рабочей версии. При открытии другого источника связь прекращается. После экспорта новое задание очереди получает текущий манифест; непересобранная рабочая версия в очередь не добавляется.
- При независимой обработке параметры и маски каждого изображения перенумеровываются локально, поэтому правка первого PNG не применяется ко всем остальным. Холсты и исходные длительности сохраняются.
- В главном просмотре готовой анимации: воспроизведение/пауза, шаг, ползунок, длительность кадра и выбор именованной анимации. Часы учитывают разные длительности и паузу; просмотр повторяется по кругу, не меняя настройки повторов экспорта. Переход в другой раздел и скрытие окна останавливают проигрывание.
- Для отдельных PNG/атласов доступны переходы между объектами без автоматического проигрывания. Для одного PNG лишние кнопки не показываются.
- Проверка PNG возвращает номер кадра и координаты наблюдений. Светлые/внутренние полупрозрачные участки ограничены до 96 прямоугольников каждого типа на кадр. Это места для просмотра, не доказательство плохой вырезки. Аналогичные наблюдения включены в отчёт атласа.
- Из отчёта можно показать кадр с отметками или открыть его маску. Бирюзовые отметки учитывают вписывание/1:1 и видимую область, отключаются отдельно и не входят в экспорт.

## Проверка

- Полный npm run verify: 501 тест, 500 прошли, 1 прежний тяжёлый AI-прогон пропущен, ошибок нет; verify-stage5.txt.
- После заключительной связи предпросмотра с рабочей маской: 50 связанных тестов, все прошли; stage5-final-focused.txt. Линтер и git diff --check без ошибок (есть прежнее предупреждение Git о CRLF в companion-loading).
- Настоящая обработка: правка -> новая сборка для animation/images/atlas -> чтение сохранённых RGBA, размеров и длительностей -> повторная обработка текущего манифеста по пути очереди. Старый файл сравнивается побайтно.
- FrameClock: 80/240/120 мс, границы кадров, пауза, ручной переход и большой пропуск времени.
- Electron из исходников, отдельные профили: конвейер -> редактор -> изменённый пиксель -> undo -> redo -> ручная маска -> актуальный просмотр -> новый экспорт -> чтение пикселя PNG -> возврат в редактор без потери правок. stage5-ui-working-final.js, stage5-working-final.png.
- Реальный просмотр GIF 80/240 мс, шаг/пуск/пауза: stage5-ui-playback.js, stage5-playback.png.
- Отчёт -> точная отметка на PNG -> вписывание/1:1 и отчёт -> маска нужного кадра: stage5-ui-marks.js / stage5-ui-mask.js, stage5-marks.png / stage5-mask.png. Проверены светлая тема 1040×700 и тёмная 1280×820.
- В расширенном UI-тесте учтена конкуренция отложенного и явного предпросмотра: перед явно ожидаемой проверкой отменяется прежний таймер. Готовность проверяется по реальному альфа-пикселю; предположение о названии временного файла не используется.
- Каждый тестовый экземпляр закрыт. Проверки собственные технические/визуальные, не независимая художественная приёмка.

## Оставшиеся границы

- Несохранённые мазки внутри редактора становятся частью рабочего результата после применения к проекту. Черновик не выдаётся за сохранённый экспорт.
- Проигрыватель главного окна работает с готовыми кадрами результата; оригинальный видеоролик не извлекается заново ради этой функции.
- Чекпоинт после сбоя по-прежнему ограничен текущим процессом и 20 минутами. Продолжение после перезапуска, продолжение отдельных заданий очереди и смена выходной папки без повторной очистки остаются отдельным пакетом.
- Реальные сравнительные замеры тяжёлых моделей/больших роликов, аппаратная приёмка и portable EXE остаются последующими шагами. Независимая художественная приёмка здесь не заявляется.
