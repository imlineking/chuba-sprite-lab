# ToonOut: CPU и GPU на одном изображении

15 октября 2026. Собственный измерительный прогон по прямому запросу пользователя. Приложение/EXE не изменялись и не пересобирались.

## Условия

- Intel Core i7-12700KF; NVIDIA GeForce RTX 4060 Ti; Windows.
- Один утверждённый цельный рисунок свиньи `ordinary-pig-left-rescue-v1/.../frames/0000.png`; к копии добавлен ровный белый фон. Оригинал не изменён, SHA-256 проверен.
- 222 345 пикселей входного кадра; одна и та же ToonOut, вход модели 1024×1024, `fast`, порог `auto`, softness 0; один и тот же штатный `processFramePreview`. Различается только `aiProvider`.
- Для CPU и DirectML создавались отдельные процессы. Первый замер включает загрузку/подготовку модели, но не загрузку JS-модулей, старт Electron или распаковку EXE. Дисковый кеш Windows не сбрасывался — это не системный «холодный старт».
- После первого обращения — три повторных запуска с загруженной моделью. Перед каждым `clearRenderCache()` очищает кеши результатов/кадров. Повторные замеры выполняют вычисление заново.
- CPU использует штатный предел приложения: два intra-op потока. Это сравнение существующих режимов приложения, а не максимально возможной загрузки всех 20 логических потоков процессора.
- Фактические провайдеры проверялись после каждого запуска: `cpu` и `dml`. Отката DirectML на CPU не было.

## Результаты

| Показатель | CPU | GPU / DirectML |
| --- | ---: | ---: |
| Первое обращение с загрузкой модели | 35,941 с | 9,836 с |
| Повтор №1 | 33,652 с | 4,689 с |
| Повтор №2 | 32,901 с | 4,493 с |
| Повтор №3 | 34,474 с | 4,650 с |
| Медиана повторных обработок | **33,652 с** | **4,650 с** |
| Среднее повторных обработок | 33,676 с | 4,611 с |
| Максимальный RSS процесса, выборка каждые 50 мс | 6 846 МиБ | 1 656 МиБ |

GPU быстрее в **7,24 раза** по медиане повторных обработок и в **3,65 раза** при первом обращении. Три повторения — короткая серия, не статистика для любых материалов и параллельной нагрузки.

RSS отражает ОЗУ процесса и не включает всю видеопамять. Его нельзя считать суммарным потреблением памяти системы. CPU-пик вырос с 4 266 МиБ после первого обращения до 6 761 МиБ после второго, затем до 6 846 МиБ и в четвёртом прогоне не увеличился. Короткая серия не подтверждает линейной утечки, но и не заменяет длительный тест.

## Качество и вывод

- Маски совпали во всех **222 345** пикселях: изменённых alpha-пикселей **0**, IoU между CPU/GPU **1,0**.
- Полные PNG CPU и GPU имеют одинаковую SHA-256; совпала не только alpha.
- Относительно исходной прозрачной фигуры: сохранено **99,7146%** непрозрачного силуэта; IoU **99,6393%** при пороге alpha > 127. Это техническая метрика данного контролируемого входа, не художественная приёмка любой вырезки.
- В обычном режиме целесообразен существующий выбор **«Авто» → DirectML**, CPU остаётся запасным вариантом. CUDA этим прогоном не проверяется и в текущем списке ускорителей приложения отсутствует.
- Прежние 44,7 с были одиночным CPU-прогоном. Для сравнения ускорителей использовать эту парную серию с явно одинаковыми настройками.

Скрипт: `scripts/benchmark-ai-compare.mjs`. Полные числа, настройки и хеши: `cpu-gpu-compare/report.json`; результаты — `cpu-gpu-compare/cpu.png` и `cpu-gpu-compare/dml.png`.
