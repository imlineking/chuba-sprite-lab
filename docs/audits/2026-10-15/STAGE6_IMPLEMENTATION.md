# Этап 6 — пункты 2–4 одним проходом

## Объём

Подтверждены пункты исходного списка оставшегося: проигрывание анимации, наглядные замечания с переходом к кадру, восстановление после сбоя. Первые два уже реализованы этапом 5; здесь они повторно проверены в общем пути с восстановлением. К другим моделям/критикам не обращались по указанию пользователя. EXE, commit и push не выполнялись.

## Реализовано

- Контрольные точки прямого конвейера и отдельных задач очереди сохраняются в userData/conveyor-checkpoints. Формат версионирован, запись атомарная; контрольная сумма проверяет целостность записи. На диске нет JSON-массивов сырых RGBA атласа.
- Временные извлечённые кадры копируются в принадлежащий задаче каталог кеша, поэтому завершение процесса и удаление временного импорта не уничтожают готовый этап. Оригинальные входные файлы по-прежнему должны существовать и совпадать по SHA-256.
- При восстановлении проверяются входы, состав входной папки, кеш и сохранённые результаты. Страницы атласа для незавершённой проверки восстанавливаются из проверенных PNG, без повторной очистки и упаковки.
- На запуске предлагается продолжить незавершённую задачу. При пустой студии открывается конвейер с предложением; после продолжения результат остаётся виден в конвейере. Чужой открытый материал автоматически не заменяется.
- У каждой неудачной задачи очереди есть продолжение/новая папка либо явный повтор с начала, если контрольной точки нет. Прерванная очередь после запуска имеет доступную кнопку продолжения. Отдельный повтор на паузе выполняет выбранную задачу и сохраняет паузу остальных.
- При выборе новой папки готовые файлы копируются, ссылки и ключи метаданных обновляются; очистка не повторяется. Если конечная папка с таким именем уже занята, создаётся отдельная папка с суффиксом resume. Старый результат и существующие файлы не перезаписываются.
- Настроенная папка очереди отделена от фактической папки результата: повтор не создаёт цепочку name/name/name. Записи очереди сериализуются, временные JSON-файлы имеют уникальные имена.
- Успех, явная отмена и удаление задачи освобождают её контрольную точку. Срок хранения в приложении — 7 дней от последнего сохранённого этапа; просроченные записи удаляются при старте/обращении. Класс без дискового хранилища сохраняет прежний 20-минутный режим для изолированных тестов.

## Границы

Это собственная техническая и визуальная проверка. Изменившиеся или отсутствующие оригиналы требуют нового запуска. Чекпоинт относится к завершённым этапам; незаконченный этап выполняется снова. Сохранение произвольного незавершённого мазка пиксельного редактора этой системой не добавлялось. Реальный совместный тяжёлый AI-прогон, замеры больших роликов и аппаратная/portable-приёмка остаются отдельной работой. EXE содержит прежнюю версию до отдельной команды на сборку.
