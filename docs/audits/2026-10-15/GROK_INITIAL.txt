Приоритетные пункты (польза → доказательство → изменение → критерий готовности)

1. Упростить главный путь копилота до одного следующего шага (высокий приоритет)

Польза: пользователь выбирает цель («отдельные PNG / атлас / анимация»), копилот показывает один основной следующий шаг + краткое объяснение, сложные параметры прячутся.

Доказательство: COPILOT_SCENARIOS_ROADMAP.md (принцип продукта, матрица 46 сценариев, контракт дирижёра); copilot.js + copilot-planner.mjs (сценарии, suggestions, rules/qwen с fallback); README описывает помощника-питомца с кнопкой «Применить».

Изменение: в UI копилота всегда один primary action + «подробнее»; убрать лишние карточки на первом экране.

Критерий: на трёх реальных входах (один PNG с фоном, папка смешанных PNG, видео) пользователь доходит до готового результата за ≤3 клика без чтения длинных текстов.

Статус: частично работает (rules + UI), не закончено (единый дирижёр для всех входов, короткие подсказки).

2. Повторяемая сборка и проверка изменений (как TexturePacker)

Польза: рецепт → CLI / watch → атомарный экспорт + инспектор (коды 0/1/2/3), без перезаписи без --clean/--version.

Доказательство: README раздел «Сборка без интерфейса» (npm run cli -- --profile … --watch --strict); ROADMAP отмечает CLI и атомарный экспорт как сделанные; COPILOT_SCENARIOS пункт 45.

Изменение: добавить в копилот кнопку «Сохранить рецепт и запустить CLI» + простой статус изменений исходников.

Критерий: изменение одного PNG → автоматическая пересборка только нужного набора, инспектор проходит, исходники не трогаются.

Статус: уже работает в CLI; в UI-копилоте — не закончено (нет короткого моста).

3. Теги, длительности и тайминг (как Aseprite)

Польза: именованные анимации, теги, длительности, опоры в JSON; импорт .aseprite.

Доказательство: ROADMAP P2 — нативный импорт .aseprite (теги, slices, длительности) выполнен; README — теги/длительности в инспекторе; COPILOT_SCENARIOS пункты 29, 39.

Изменение: в копилоте для видео/GIF сразу предлагать «разметить теги по сходству» с подтверждением, без полного редактора.

Критерий: импорт .aseprite → JSON с тегами сохраняется, цикл не дрожит (эталон клубка).

Статус: работает в исходниках; автоматическая группировка — не закончено.

4. Обратимые эффекты и просмотр серии (как Pixelorama)

Польза: история/undo на пакет, сравнение исходник/результат, подложки, предпросмотр до записи.

Доказательство: ROADMAP — пакетная отмена одной операцией, сравнение, подложки; copilot.js поддерживает undoAdvice; README — Ctrl+Z, сравнение кадров.

Изменение: в копилоте всегда показывать «отменить весь шаг» и кнопку «сравнить на подложках» рядом с результатом.

Критерий: после автоочистки папки одна отмена возвращает все файлы, исходники целы.

Статус: работает; не закончено — автоматическая оценка качества результата (сейчас ручной просмотр).

5. Разрывы ручная студия ↔ автоматика

Польза: закрыть случаи, где копилот останавливается и требует ручного вмешательства.

Доказательство: COPILOT_SCENARIOS (пункты 7, 16, 18, 20, 21 — частично/исследование); copilot-planner.mjs (validatePlannerResponse строго ограничивает сценарии, fallback на rules); ROADMAP P3 — замкнутый цикл и VLM как эксперименты.

Изменение: добавить 2–3 коротких «ручных развилки» (защитить детали / ограничить область / отменить нормализацию) прямо в карточке копилота.

Критерий: на спорном белом цветке или нити/хвосте пользователь выбирает один вариант, результат обратимый.

Статус: частично; новое — короткие развилки без перегруза.
