# Выпуск 1.10.1 — 21 октября 2026

Однофайловый Windows EXE пересобран по прямой команде пользователя из актуальных исходников без Qwen-критика и нейропланировщика. Приёмка работает алгоритмами, помощник — по правилам. Удалены JS-runtime, статус и маршруты IPC модельного планировщика. Подробности исходникового аудита — [REPORT.md](REPORT.md).

## Артефакт

- Путь: `portable/Chuba Sprite Lab.exe`; размер: 1 346 640 480 байт.
- SHA-256: `9bb72dbf7053070e7c74f6aacdd86e1f558d3b1ee24717c21383735fdb7fc1ad`.
- Версия в package.json, lockfile, разметке и запущенном renderer: 1.10.1.
- Ярлыки Desktop/Sprite Lab.lnk и lab/Sprite Lab.lnk указывают на новый EXE по прежнему пути.
- В комплекте 5 специализированных моделей: ToonOut, LaMa, RIFE, Real-ESRGAN, Depth Anything V2 small. Для вырезки используется ToonOut.

## Что проверено

1. `npm run pack`: fresh win-unpacked, архив 7z создан и проверен до упаковки в EXE.
2. Проверены 2420 файлов ресурсов; нет Qwen, llama-server, GGUF, llm-runtime, resource-policy и critic-status. Все 154 файла src совпали с рабочими исходниками.
3. Повторная проверка фактически распакованного новым EXE содержимого в LocalAppData: те же исходники и отсутствие компонентов VLM. Это проверка артефакта, не только package.json.
4. `npm run verify` после сборки: 508 тестов, 507 пройдены, 1 пропущен, 0 ошибок. После уточнения тайм-аута UI-harness повторно прошёл ESLint.
5. Реальный EXE, отдельный диагностический профиль, `--self-test --self-test-all-models`: Sharp, FFmpeg, ToonOut (DirectML, вход 1024) и вычисление всех четырёх вспомогательных моделей — успешно.
6. Реальный EXE, packaged UI: версия, отсутствие старых VLM-мостов и Node integration в renderer, импорт PNG в параллакс, правка слоя, undo/redo, анимированная камера и остановка RAF. Исключений нет.

Исходник неизменён; сохранённые пиксели соответствуют предпросмотру; исключений нет. Проверены обе темы и размеры окон, предусмотренные harness.

Машиночитаемая сводка: [RELEASE_1_10_1.json](RELEASE_1_10_1.json). Локальные логи и изображения: `.diagnostics/release-1.10.1/`.

## Найденное ограничение первого запуска

Офлайн-пакет требует холодной распаковки около 2 ГБ. Прежний UI-harness ждал 60 секунд и остановил launcher до завершения извлечения; повторный запуск тогда встретил занятый `7za.exe` во временной папке. После завершения блокировки повторная распаковка и все self-test прошли. Тест теперь ждёт до 300 секунд, код извлечения и защита Windows не менялись. Последующие запуски используют готовый проверенный кеш.

Первый запуск image-workflow на одноцветной тестовой плашке был непригодным для сценария проверки удаления фона: объект закономерно не сохранился. Итоговый прогон выполнен на реальном спрайте подсолнуха, результаты выше относятся к нему.

Эта проверка не подтверждает запуск на чистой Windows и не является эталонной оценкой всех масок. Старые веса Qwen в папках проекта, прежний extraction-cache и архив прежнего portable — вне нового артефакта; их удаление этим выпуском не заявляется. GitHub Release с бинарным вложением не публиковался.
