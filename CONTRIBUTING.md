# Contributing

Bug reports and focused pull requests are welcome. Before proposing a change:

1. Create or reference an issue describing the problem.
2. Keep changes limited to one purpose.
3. Run `npm run verify`.
4. Do not commit generated builds, FFmpeg binaries, personal media, or exported sprite assets.

Submitting a contribution grants Hanuman Media Company — Demidenko Dmitriy permission to review, modify, and include that contribution in Chuba Sprite Lab. It does not change the proprietary status of the project or grant rights to unrelated project code and assets.
