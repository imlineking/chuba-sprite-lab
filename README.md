# Chuba Sprite Lab

Современный локальный Windows-инструмент для превращения видео и последовательностей изображений в готовые игровые спрайт-листы.

**Автор и правообладатель:** Hanuman Media Company — Demidenko Dmitriy

**Год:** 2026

**Официальный репозиторий:** [imlineking/chuba-sprite-lab](https://github.com/imlineking/chuba-sprite-lab)

## Скачать

Откройте раздел [Releases](https://github.com/imlineking/chuba-sprite-lab/releases/latest) и скачайте единственный файл:

```text
Chuba-Sprite-Lab-portable.exe
```

Установка не требуется. FFmpeg, Sharp и необходимые компоненты уже находятся внутри portable EXE. Для обновления откройте меню `?` в правом верхнем углу программы и нажмите **«Проверить обновления»**.

## Возможности

- MP4, WebM, MOV, MKV, AVI, GIF и наборы PNG/JPG/WebP;
- пакетная обработка нескольких видео по одним настройкам;
- автоматические имена наборов без перезаписи существующих результатов;
- встроенный FFmpeg и полностью локальная обработка;
- анализ трёх контрольных кадров и объяснимая автонастройка;
- удаление белого, чёрного, зелёного, синего или автоматически найденного фона;
- сохранение защищённого тёмного контура при удалении чёрного фона;
- сравнение исходного и очищенного кадра;
- стабилизация по земле, центру или исходному движению;
- авторазмер ячейки и автоматическая сетка;
- экспорт PNG-атласа, отдельных кадров, JSON, отчёта и lossless WebP;
- обратимое исключение кадров и диагностика скачков силуэта;
- встроенная проверка обновлений GitHub Releases с обязательной SHA-256-проверкой.

## Пакетная обработка

Выделите несколько видео в окне выбора источника. Автонастройка и предпросмотр строятся по первому ролику, после чего выбранные параметры применяются ко всей очереди. Каждый ролик сохраняется в отдельную папку с именем исходного файла. Если имя занято, создаётся версия `-2`, `-3` и далее.

Ошибка одного ролика не останавливает оставшуюся очередь. В конце программа показывает число готовых наборов и список файлов, которые не удалось обработать.

## Приватность

Программа не отправляет исходные видео, изображения или результаты обработки на сервер. Интернет используется только по прямому нажатию кнопки проверки обновлений — для чтения метаданных официального GitHub Release и загрузки нового portable EXE.

## Системные требования

- Windows 10 или Windows 11, x64;
- свободное место для исходных кадров и результатов;
- подключение к интернету требуется только для обновлений.

## Разработка

```powershell
npm ci
npm run prepare:vendor
npm run verify
npm run pack
```

Однофайловая сборка появится здесь:

```text
dist/Chuba-Sprite-Lab-portable.exe
```

Команда `npm run release:build` дополнительно создаёт EXE и SHA-256 в папке `release/`.
